## 播放功能概述

mod_audio_stream 支持**双向音频流**，这意味着：

- **发送音频**: 将呼叫者的音频流式传输到 WebSocket 服务器
- **接收音频**: 从 WebSocket 服务器接收音频并播放给呼叫者

### 关键特性

✅ 支持多种音频格式（raw, wav, mp3, ogg, pcmu, pcma）  
✅ 自动解码 base64 编码的音频  
✅ 临时文件自动管理和清理  
✅ 通过事件系统通知音频可播放  
✅ 与 FreeSWITCH 播放命令无缝集成

## 工作原理

### 1. WebSocket 服务器发送音频

服务器需要发送符合以下格式的 JSON 消息：

```json
{
  "type": "streamAudio",
  "data": {
    "audioDataType": "raw",
    "sampleRate": 8000,
    "audioData": "AAAA//7+/v7+/v7+..."
  }
}
```

**字段说明**：

| 字段 | 说明 | 可选值 |
|------|------|--------|
| `type` | 必须为 "streamAudio" | - |
| `audioDataType` | 音频数据类型 | raw, wav, mp3, ogg, pcmu, pcma |
| `sampleRate` | 采样率（仅 raw 格式需要） | 8000, 16000, 24000, 32000, 48000, 64000 |
| `audioData` | Base64 编码的音频数据 | - |

### 2. mod_audio_stream 处理

模块收到 `streamAudio` 消息后：

1. **解码音频数据**: 从 base64 解码为二进制数据
2. **保存到临时文件**: 根据音频类型创建临时文件
   - raw 格式: `/tmp/freeswitch/audio_xxxxx.r8`（根据采样率）
   - wav 格式: `/tmp/freeswitch/audio_xxxxx.wav`
   - mp3 格式: `/tmp/freeswitch/audio_xxxxx.mp3`
   - 其他格式类似
3. **触发事件**: 发送 `mod_audio_stream::play` 事件

### 3. 事件格式

`mod_audio_stream::play` 事件包含以下信息：

```json
{
  "audioDataType": "raw",
  "sampleRate": 8000,
  "file": "/tmp/freeswitch/audio_12345678.r8"
}
```

**重要**: 原始的 base64 音频数据不会包含在事件中（避免事件过大），取而代之的是临时文件路径。

## 播放音频的步骤

### 方法一：使用拨号计划自动播放

在拨号计划中监听事件并自动播放。

#### 步骤 1: 配置拨号计划

```xml
<extension name="audio_stream_with_playback">
  <condition field="destination_number" expression="^9100$">
    <action application="answer"/>
    
    <!-- 启动音频流 -->
    <action application="uuid_audio_stream" 
            data="${uuid} start ws://your-server.com:8080/stream mono 8k"/>
    
    <!-- 执行 Lua 脚本处理播放 -->
    <action application="lua" data="audio_playback_handler.lua"/>
    
    <!-- 停止音频流 -->
    <action application="uuid_audio_stream" data="${uuid} stop"/>
    
    <action application="hangup"/>
  </condition>
</extension>
```

#### 步骤 2: 创建 Lua 脚本

创建 `/usr/share/freeswitch/scripts/audio_playback_handler.lua`:

```lua
-- 订阅 mod_audio_stream::play 事件
local con = freeswitch.EventConsumer("CUSTOM", "mod_audio_stream::play")

-- 获取会话信息
local uuid = session:getVariable("uuid")

-- 监听播放事件（最多等待 60 秒）
for i = 1, 60 do
    local event = con:pop(1)  -- 等待 1 秒
    
    if event then
        local event_uuid = event:getHeader("Unique-ID")
        
        -- 确认是当前会话的事件
        if event_uuid == uuid then
            local body = event:getBody()
            freeswitch.consoleLog("info", "收到播放事件: " .. body .. "\n")
            
            -- 解析 JSON 获取文件路径
            local cjson = require("cjson")
            local data = cjson.decode(body)
            
            if data.file then
                freeswitch.consoleLog("info", "播放文件: " .. data.file .. "\n")
                
                -- 播放音频文件
                session:streamFile(data.file)
                
                -- 或使用 execute
                -- session:execute("playback", data.file)
            end
        end
    end
    
    -- 检查会话是否仍然活动
    if not session:ready() then
        break
    end
end
```

### 方法二：使用 Python ESL 控制播放

更灵活的方式是使用 ESL 监听事件并控制播放。

```python
#!/usr/bin/env python3
import ESL
import json

class AudioPlaybackController:
    """音频播放控制器"""
    
    def __init__(self):
        self.con = ESL.ESLconnection("localhost", "8021", "ClueCon")
        
        if not self.con.connected():
            raise Exception("无法连接到 FreeSWITCH")
    
    def start_monitoring(self):
        """开始监听播放事件"""
        # 订阅 mod_audio_stream::play 事件
        self.con.events("plain", "CUSTOM mod_audio_stream::play")
        
        print("开始监听音频播放事件...")
        
        while True:
            e = self.con.recvEvent()
            
            if e:
                event_subclass = e.getHeader("Event-Subclass")
                
                if event_subclass == "mod_audio_stream::play":
                    self.handle_play_event(e)
    
    def handle_play_event(self, e):
        """处理播放事件"""
        uuid = e.getHeader("Unique-ID")
        body = e.getBody()
        
        try:
            data = json.loads(body)
            file_path = data.get("file")
            audio_type = data.get("audioDataType")
            sample_rate = data.get("sampleRate")
            
            print(f"\n{'='*60}")
            print(f"收到播放请求:")
            print(f"  通道 UUID: {uuid}")
            print(f"  音频类型: {audio_type}")
            print(f"  采样率: {sample_rate}")
            print(f"  文件路径: {file_path}")
            
            if file_path:
                # 播放音频到通道
                self.play_audio(uuid, file_path)
            
        except json.JSONDecodeError as e:
            print(f"JSON 解析错误: {e}")
    
    def play_audio(self, uuid, file_path):
        """播放音频到指定通道"""
        # 方法 1: 使用 uuid_broadcast（推荐，不会中断当前音频）
        cmd = f"uuid_broadcast {uuid} {file_path} both"
        result = self.con.api(cmd)
        
        if result:
            response = result.getBody().strip()
            if response == "+OK":
                print(f"  ✓ 开始播放: {file_path}")
            else:
                print(f"  ✗ 播放失败: {response}")
        
        # 方法 2: 使用 uuid_displace（混音播放）
        # cmd = f"uuid_displace {uuid} start {file_path} 0 m"
        # self.con.api(cmd)

# 使用示例
if __name__ == "__main__":
    try:
        controller = AudioPlaybackController()
        controller.start_monitoring()
    except KeyboardInterrupt:
        print("\n停止监听")
```

### 方法三：使用事件套接字实时控制

对于需要更精细控制的场景：

```python
#!/usr/bin/env python3
import ESL
import json
import threading

def monitor_and_play(uuid):
    """监控特定通道的播放事件"""
    con = ESL.ESLconnection("localhost", "8021", "ClueCon")
    
    if not con.connected():
        print("连接失败")
        return
    
    # 订阅事件
    con.events("plain", "CUSTOM mod_audio_stream::play")
    
    # 只关注特定 UUID 的事件
    con.filter("Unique-ID", uuid)
    
    print(f"监听通道 {uuid} 的播放事件...")
    
    while True:
        e = con.recvEventTimed(100)  # 100ms 超时
        
        if e:
            event_subclass = e.getHeader("Event-Subclass")
            
            if event_subclass == "mod_audio_stream::play":
                body = e.getBody()
                data = json.loads(body)
                file_path = data.get("file")
                
                if file_path:
                    print(f"播放音频: {file_path}")
                    
                    # 立即播放
                    con.api(f"uuid_broadcast {uuid} {file_path} both")

# 启动监控线程
uuid = "your-channel-uuid"
thread = threading.Thread(target=monitor_and_play, args=(uuid,))
thread.daemon = True
thread.start()
```

## 停止和控制播放

### 停止正在播放的音频

#### 方法 1: 停止 uuid_broadcast

```bash
# 在 fs_cli 中
uuid_broadcast <uuid> stop
```

```python
# 使用 Python ESL
con.api(f"uuid_broadcast {uuid} stop")
```

#### 方法 2: 停止 uuid_displace

如果使用 `uuid_displace` 播放：

```bash
# 停止混音播放
uuid_displace <uuid> stop <file_path>
```

```python
# 使用 Python ESL
con.api(f"uuid_displace {uuid} stop {file_path}")
```

### 暂停和恢复音频流

虽然不能直接暂停播放，但可以控制音频流本身：

```python
# 暂停音频流（停止接收新音频）
con.api(f"uuid_audio_stream {uuid} pause")

# 恢复音频流
con.api(f"uuid_audio_stream {uuid} resume")
```

### 清除播放队列

```python
# 清除所有正在播放的音频
con.api(f"uuid_break {uuid} all")
```

### 示例 1: 智能 IVR 系统

实现一个 IVR 系统，服务器根据用户输入返回语音提示。

**服务器端（Node.js）**:

```javascript
const WebSocket = require('ws');
const fs = require('fs');

const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', (ws) => {
    console.log('客户端已连接');
    
    ws.on('message', (message) => {
        if (typeof message === 'string') {
            // 文本消息 - 用户输入
            console.log('收到文本:', message);
            
            const data = JSON.parse(message);
            
            if (data.userInput === '1') {
                // 用户按了 1，发送账户信息语音
                sendAudioResponse(ws, './audio/account_info.wav', 'wav');
            } else if (data.userInput === '2') {
                // 用户按了 2，发送客服语音
                sendAudioResponse(ws, './audio/customer_service.wav', 'wav');
            }
        } else {
            // 二进制音频数据
            console.log('收到音频:', message.length, '字节');
        }
    });
});

function sendAudioResponse(ws, audioFile, audioType) {
    // 读取音频文件
    const audioData = fs.readFileSync(audioFile);
    
    // Base64 编码
    const base64Audio = audioData.toString('base64');
    
    // 发送 streamAudio 消息
    const response = {
        type: 'streamAudio',
        data: {
            audioDataType: audioType,
            sampleRate: 8000,  // 仅 raw 格式需要
            audioData: base64Audio
        }
    };
    
    ws.send(JSON.stringify(response));
    console.log('已发送音频:', audioFile);
}

console.log('WebSocket 服务器运行在 ws://localhost:8080');
```

**FreeSWITCH 端（Python ESL）**:

```python
#!/usr/bin/env python3
import ESL
import json
import time

class IVRPlaybackManager:
    """IVR 播放管理器"""
    
    def __init__(self):
        self.con = ESL.ESLconnection("localhost", "8021", "ClueCon")
        
        if not self.con.connected():
            raise Exception("连接失败")
        
        self.active_channels = {}
    
    def handle_call(self, uuid):
        """处理呼叫"""
        print(f"处理呼叫: {uuid}")
        
        # 启动监听线程
        import threading
        thread = threading.Thread(target=self.monitor_playback, args=(uuid,))
        thread.daemon = True
        thread.start()
        
        # 启动音频流
        cmd = f"uuid_audio_stream {uuid} start ws://localhost:8080/stream mono 8k"
        self.con.api(cmd)
        
        # 发送初始提示
        initial_message = json.dumps({"type": "greeting"})
        self.con.api(f"uuid_audio_stream {uuid} send_text {initial_message}")
        
        # 等待用户输入
        time.sleep(30)
        
        # 停止音频流
        self.con.api(f"uuid_audio_stream {uuid} stop")
    
    def monitor_playback(self, uuid):
        """监控播放事件"""
        # 创建新连接用于事件监听
        con = ESL.ESLconnection("localhost", "8021", "ClueCon")
        con.events("plain", "CUSTOM mod_audio_stream::play")
        con.filter("Unique-ID", uuid)
        
        while True:
            e = con.recvEventTimed(100)
            
            if e:
                event_subclass = e.getHeader("Event-Subclass")
                
                if event_subclass == "mod_audio_stream::play":
                    body = e.getBody()
                    data = json.loads(body)
                    file_path = data.get("file")
                    
                    if file_path:
                        print(f"[{uuid}] 播放音频: {file_path}")
                        
                        # 播放音频
                        self.con.api(f"uuid_broadcast {uuid} {file_path} both")

# 使用示例
if __name__ == "__main__":
    manager = IVRPlaybackManager()
    
    # 假设有一个呼叫
    uuid = "your-channel-uuid"
    manager.handle_call(uuid)
```

### 示例 3: 多音频队列播放

按顺序播放多个音频文件。

```python
#!/usr/bin/env python3
import ESL
import json
import queue
import threading

class AudioQueuePlayer:
    """音频队列播放器"""
    
    def __init__(self):
        self.con = ESL.ESLconnection("localhost", "8021", "ClueCon")
        
        if not self.con.connected():
            raise Exception("连接失败")
        
        self.audio_queues = {}  # uuid -> queue
        self.playing = {}       # uuid -> bool
    
    def start_monitoring(self):
        """开始监控"""
        self.con.events("plain", "CUSTOM mod_audio_stream::play")
        self.con.events("plain", "CHANNEL_HANGUP")
        
        print("音频队列播放器已启动")
        
        while True:
            e = self.con.recvEvent()
            
            if e:
                event_name = e.getHeader("Event-Name")
                
                if event_name == "CUSTOM":
                    self.handle_play_event(e)
                elif event_name == "CHANNEL_HANGUP":
                    self.handle_hangup(e)
    
    def handle_play_event(self, e):
        """处理播放事件"""
        uuid = e.getHeader("Unique-ID")
        body = e.getBody()
        
        try:
            data = json.loads(body)
            file_path = data.get("file")
            
            if file_path:
                # 添加到队列
                if uuid not in self.audio_queues:
                    self.audio_queues[uuid] = queue.Queue()
                    self.playing[uuid] = False
                
                self.audio_queues[uuid].put(file_path)
                print(f"[{uuid}] 音频入队: {file_path}")
                
                # 如果没有正在播放，开始播放
                if not self.playing.get(uuid, False):
                    self.play_next(uuid)
                    
        except Exception as e:
            print(f"错误: {e}")
    
    def play_next(self, uuid):
        """播放队列中的下一个音频"""
        if uuid not in self.audio_queues:
            return
        
        try:
            file_path = self.audio_queues[uuid].get_nowait()
            
            print(f"[{uuid}] 播放: {file_path}")
            self.playing[uuid] = True
            
            # 播放音频
            result = self.con.api(f"uuid_broadcast {uuid} {file_path} both")
            
            # 启动线程等待播放完成
            thread = threading.Thread(target=self.wait_and_play_next, args=(uuid, file_path))
            thread.daemon = True
            thread.start()
            
        except queue.Empty:
            print(f"[{uuid}] 队列为空")
            self.playing[uuid] = False
    
    def wait_and_play_next(self, uuid, file_path):
        """等待当前音频播放完成，然后播放下一个"""
        import time
        import os
        
        # 简单估算播放时间（实际应该监听播放完成事件）
        try:
            file_size = os.path.getsize(file_path)
            # 假设 8kHz, 16bit, mono: 16000 bytes/sec
            duration = file_size / 16000 + 1
            
            time.sleep(duration)
            
            print(f"[{uuid}] 播放完成: {file_path}")
            
            # 播放下一个
            self.play_next(uuid)
            
        except Exception as e:
            print(f"等待播放完成时出错: {e}")
            self.playing[uuid] = False
    
    def handle_hangup(self, e):
        """处理挂断"""
        uuid = e.getHeader("Unique-ID")
        
        if uuid in self.audio_queues:
            del self.audio_queues[uuid]
        if uuid in self.playing:
            del self.playing[uuid]
        
        print(f"[{uuid}] 通道挂断，清理队列")

# 使用示例
if __name__ == "__main__":
    try:
        player = AudioQueuePlayer()
        player.start_monitoring()
    except KeyboardInterrupt:
        print("\n停止播放器")
```

## 常见问题

### 问题 1: 收到播放事件但音频没有播放

**可能原因**:
1. 临时文件路径不正确
2. 通道已挂断或不可用
3. 音频格式不被 FreeSWITCH 支持

**解决方案**:

```python
# 检查文件是否存在
import os

if os.path.exists(file_path):
    print(f"文件存在: {file_path}")
else:
    print(f"文件不存在: {file_path}")

# 检查通道是否存在
result = con.api(f"uuid_exists {uuid}")
if result and result.getBody().strip() == "true":
    print("通道存在")
    
    # 尝试播放
    play_result = con.api(f"uuid_broadcast {uuid} {file_path} both")
    print(f"播放结果: {play_result.getBody()}")
else:
    print("通道不存在")
```

### 问题 2: 音频播放被中断

**原因**: `uuid_broadcast` 默认会中断当前正在播放的音频。

**解决方案**: 使用音频队列或 `uuid_displace` 混音播放：

```python
# 使用 uuid_displace 混音播放（不会中断）
con.api(f"uuid_displace {uuid} start {file_path} 0 m")

# 停止混音
# con.api(f"uuid_displace {uuid} stop {file_path}")
```

### 问题 3: 临时文件没有被清理

**原因**: 会话异常终止或模块未正确清理。

**解决方案**: 

临时文件通常在会话结束时自动清理。如果需要手动清理：

```bash
# 清理所有 mod_audio_stream 临时文件
find /tmp/freeswitch -name "audio_*.r*" -mtime +1 -delete
find /tmp/freeswitch -name "audio_*.wav" -mtime +1 -delete
find /tmp/freeswitch -name "audio_*.mp3" -mtime +1 -delete
```

或在代码中：

```python
import glob
import os

# 清理旧的临时文件
for pattern in ["/tmp/freeswitch/audio_*.r*", 
                "/tmp/freeswitch/audio_*.wav",
                "/tmp/freeswitch/audio_*.mp3"]:
    for file_path in glob.glob(pattern):
        try:
            os.remove(file_path)
            print(f"已删除: {file_path}")
        except Exception as e:
            print(f"删除失败: {file_path}, {e}")
```

### 问题 4: 音频质量差或有噪音

**原因**: 采样率不匹配或音频格式错误。

**解决方案**:

1. **确保采样率正确**:
```json
{
  "type": "streamAudio",
  "data": {
    "audioDataType": "raw",
    "sampleRate": 8000,  // 必须与实际音频匹配
    "audioData": "..."
  }
}
```

- 确保音频编码为 L16 PCM

3. **转换音频格式**:

**方法 2: 估算播放时间**

```python
import os

def estimate_duration(file_path, sample_rate=8000):
    """估算音频播放时长（秒）"""
    file_size = os.path.getsize(file_path)
    
    # raw 格式: 16bit (2 bytes) per sample
    bytes_per_second = sample_rate * 2
    
    duration = file_size / bytes_per_second
    return duration

# 使用
duration = estimate_duration(file_path, 8000)
print(f"预计播放时长: {duration:.2f} 秒")
```
